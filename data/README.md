# Northshore League match dataset

Synthetic event data for a fictional four-club league (Vellmoor Athletic, Saltreach Mariners, Corranvale City, Embergate United). Every club, player and match here is generated by `app/simulator`; no real-world data is used as input.

## Files

`match_<seed>.jsonl`: one full 90-minute match, one `MatchEvent` per line in `seq` order. The committed samples are seeds 7, 8 and 9. Regenerate or create more with:

```
python -m app.simulator.run --seed 7 --export data/match_7.jsonl
```

The same seed always produces the identical file.

## Event schema (`app/simulator/model.py`)

| Field | Type | Notes |
| --- | --- | --- |
| `match_id` | str | `m<seed>-<home>-<away>`, e.g. `m0007-cor-vel` |
| `seq` | int | 0-based, strictly increasing per match |
| `minute`, `second` | int | match clock; second half starts at 45:00, stoppage only in the second half, so the clock never runs backwards |
| `type` | str | `pass`, `shot`, `tackle`, `interception`, `pressure`, `possession_change`, `substitution`, `foul`, `goal`, `kickoff`, `half_time`, `full_time` |
| `team_id` | str | acting club (`vel`, `sal`, `cor`, `emb`); `match` for half_time and full_time |
| `player_id` | str or null | `<club>-<shirt>`, e.g. `vel-09` |
| `x`, `y` | float | 0-100, from the acting team's view, attacking left to right (x=100 is the opponent's goal line) |
| `end_x`, `end_y` | float or null | pass target or shot target |
| `outcome` | `success`, `fail` or null | pass completed, shot on target, tackle or interception won |
| `meta` | object | type-specific values, below |

Pitch size for metre conversions: 105 x 68 m.

### `meta` keys

| Event | Keys |
| --- | --- |
| every event | `period` (1 or 2) |
| `pass` | `pass_length_m`, `carry_m` (metres carried before the pass), `speed_kmh` (carrier speed), `under_pressure` (0 or 1), `phase`, `receiver_id` (empty when the pass failed) |
| `shot` | `xg`, `speed_kmh` (shot speed), `phase`, `build_up_passes` |
| `pressure` | `speed_kmh` (presser's closing speed), `phase` |
| `tackle`, `interception`, `foul` | `phase` |
| `possession_change` | `reason`: `interception`, `tackle`, `out_of_play`, `save`, `goal_kick` |
| `substitution` | `player_id` comes on, `off` goes off |
| `goal`, `kickoff`, `half_time`, `full_time` | `score_home`, `score_away` (`goal` also has `xg`) |

`phase` is one of `build_up`, `transition`, `pressing`, `set_piece`.
