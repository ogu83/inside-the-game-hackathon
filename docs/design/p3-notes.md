# P3 implementation notes

Concrete changes for `frontend/index.html` and `frontend/style.css`, in priority order. Each item is one commit. **[video]** marks the items that matter most for the 2-minute video; do those first if time runs short. Follow `docs/design/style-guide.md` for every value.

Limits (from the P1 brief): one HTML page, Vue 3 from the CDN, one CSS file, no build step, no npm. Lucide icons as inline SVG. Google Fonts only, two families.

Must keep working after every commit: voice toggle, push-to-talk (press and hold, release, Space key), profile selects applying on change, Q&A cards, timeline filters, phone width (390 px) and 1440x900. Run the test suite and click through one match at both sizes before each commit.

## Order

1. **[video] Tokens and fonts.** Replace the `:root` palette with the style-guide tokens (`--bg`, `--chrome`, `--panel`, `--chip`, `--line`, `--text`, `--text-2`, `--muted`, `--clock`, `--kby`, `--iva`, `--info`, `--verified`, `--rewritten`, `--rejected`, `--pitch-a`, `--pitch-b`). Map `--home` to `--kby`, `--away` to `--iva`, remove `--accent` green. Add the Google Fonts link (Barlow Condensed 500/600/700, Barlow 400/500/600) and set the font stacks. Add the global focus outline. Buttons: primary `--kby` with dark text, secondary `--panel` with a `--line` border, radius 10, min height 44.
2. **[video] Pitch texture.** Mowing-stripe `<pattern>`, line opacity 0.82, vignette rect, keep `viewBox 0 0 105 68`. Move the team names out of the pitch corners into a legend row above it (colour dot plus "Kestrel Bay attack left to right", matching the real direction from `teams`).
3. **[video] Ball, trail, label.** Ball white with a club-colour stroke and a glow; trail in the possessing club's colour, dotted; the player label becomes an absolutely positioned HTML pill (convert SVG coordinates to percent of the pitch box). 250 ms tween on `cx/cy` via CSS `transition` (SVG geometry properties transition in modern browsers), disabled under `prefers-reduced-motion`.
4. **[video] Cue banner as a lower third.** Crest block in the club colour (use the 256 px PNGs), headline, subline (from the cue's supporting fact if present, else hide), Verified chip with a check icon plus "numbers by code, wording by model, attempt N", big metric column. Enter/exit motion from the style guide. Rewritten cues show the Rewritten chip instead.
5. **[video] Header and scoreboard.** League mark plus "Matchday Companion" and a small "Meridian League" line; a scoreboard pill (crest, short name, score, crest, gold clock); chips "Broadcast delay 20 s" (clock icon) and "Foundry agents live" (shield-check) or "Offline agents: reason" (triangle-alert, `--rewritten`). Move seed / speed / delay inputs out of the header: keep a 1x/4x segmented control visible, put seed and delay in a small "Match settings" popover or behind the start button (demo seed 30 stays the default). Stop becomes an icon button with `aria-label`.
6. **[video] Voice bar.** Waveform glyph (static bars, animated only while speaking), "Speaking, en" label in caps, the line in 16 px `--text`, audit on the right as "Speech audit 13 of 13 exact" with shield-check in `--verified`, "6 interrupted" in `--muted`. When push-to-talk is held show a "Paused for you" chip.
7. **[video] Push-to-talk states.** One button with the six states from the PushToTalk mockup: idle (light button, mic icon, "Hold to talk"), listening (`--kby` fill, live bars, "Listening, release to ask", 3 px focus ring), transcribing ("Got it" plus the transcript shown at once), answering (green bars, "Speaking the answer"), not heard (`--rewritten` notice "I didn't catch that, try again", no card), voice off (text box is primary, arrow-right submit button). Keep all existing pointer and key handlers.
8. **[video] Answer card.** "You asked at 19:02, Türkçe: ..." meta line with a mic icon, answer in 19 px, chips Verified / Spoken verbatim / tool names as chips, plus the timing bar (transcribe, agent and tools, check, first audio) with the numbers underneath, from the existing timing fields. "No data" answers use the info chip. One "current" card on top, older cards move into the feed.
9. **[video] Agent timeline drawer.** Footer summary row always visible (cues aired, skipped, rejected in `--rejected`, number checks with failed count, answer p50) and an "Open timeline" button. Open state: left column list of moments (time, title, verdict chip), right column the selected moment as agent steps (Analyst, Commentator, Fact-Checker, Producer) with a coloured dot, the rejected step on a tinted `rgba(255,93,108,.07)` background, the failed attempt struck through, the check reason in monospace, and "Never aired: no overlay, no voice, no fan narrative". Filter chips with counts and icons. Show the trace id when the trace exporter is on (T10 tracing).
10. **Fan profile controls.** Club and player as styled selects with the crest and shirt number, Casual/Analyst and English/Türkçe as segmented controls (they still apply on change; keep the "change pending" note, styled as a `--chip`).
11. **Ticker and narrative feed.** Ticker as three cards (time in `--clock`, Barlow 13). Narrative items on `--chrome` cards with the time in Condensed.
12. **Phone layout (max-width 600 px).** Follow the Phone mockup: compact header with the scoreboard row and short chips, full-width pitch, the cue banner overlapping the pitch bottom, voice line card, profile row, current answer card, full-width 64 px push-to-talk pinned near the bottom, and a three-tab bottom bar (Live, Feed, Agents) that swaps the lower content. Check that no element scrolls sideways at 390 px.
13. **Status and error states.** Same chip-plus-icon pattern for: offline agents (with reason), live-run limit reached ("Live runs used for today, playing with offline agents"), demo busy ("The demo is busy, try again in a minute" with the retry time if known), voice unavailable (volume-x, text answers still work), microphone denied (mic-off, "Microphone blocked, type your question instead", focus moves to the text box). Never a raw error string.
14. **Favicon and meta.** League mark as favicon, `<title>Matchday Companion</title>`, an Open Graph image from `thumbnail-bg.jpg`.
15. **Final accessibility pass.** Contrast check of every text/background pair against the tokens, `aria-live="polite"` on the voice line and the answer card, `aria-pressed` on toggles and segments, keyboard path through start, talk (Space), text box, drawer.
